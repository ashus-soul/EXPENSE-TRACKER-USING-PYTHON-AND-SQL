# 💰 CLI Expense Tracker (Python & SQLite)

A lightweight CLI expense tracker built with Python and SQLite to manage wallet balances and track categorized spending locally.

---

## ⚡ Features

* **Persistent Storage**: Saves all transactions locally in `expenserecord.db`.
* **Dynamic Balance Tracking**: Auto-calculates remaining funds after each purchase.
* **Categorized Spending**: Tag expenses under Shopping, Food, Entertainment, or Social.
* **Transaction History**: View full logs directly in the terminal.

---

## 🛠️ Tech Stack

* **Language**: Python 3.x
* **Database**: SQLite3 (Built-in standard library)
